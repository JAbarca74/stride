# Backtest validation results

Generated by the SPEC 9 validation protocol on the stored prices:

```bash
python -m stride.data.update prices      # data/stride.db up to date
python -m stride.backtest.validation     # writes this folder; exit code 1 if Phase 3 fails
```

| File | Contents |
| --- | --- |
| `validation.md` | Phase 3 verdict, walk-forward (out of sample only), sensitivity +-20%, block bootstrap, leverage comparison |
| `validation.json` | The same numbers, machine-readable |
| `backtest.html` | Full-period report: equity curve against SPY and 60/40, metrics, correlations |

Results are committed as they come out. Parameters are never changed to make a run pass (SPEC 9, 12).
