# Code of Conduct

This project follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standards

Be respectful and constructive. Welcome questions from people at every level. Critique code and ideas, not people.

Not acceptable:

- harassment, insults, or personal or political attacks;
- sexualized language or imagery;
- publishing someone's private information without permission;
- promoting financial products, signals, "guaranteed returns", referral links or spam;
- any other conduct that would be inappropriate in a professional setting.

## Scope

This applies in issues, pull requests, discussions and any other project space, and when someone represents the project elsewhere.

## Enforcement

Report unacceptable behavior privately to the maintainer through GitHub (the **Report content** option, or a private security advisory if it involves a security issue). Reports are reviewed promptly and kept confidential.

The maintainer may edit or remove comments, close issues or pull requests, and temporarily or permanently block anyone whose behavior breaks this code.
